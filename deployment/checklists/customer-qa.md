# Customer Experience QA Checklist

Run this checklist on staging before sharing a customer URL.

## Displays

- [ ] 2560 x 1600
- [ ] 1920 x 1080
- [ ] 1440 x 900

## Browsers

- [ ] Chrome latest
- [ ] Edge latest

## Golden Commands

- [ ] `show top 10 graphite projects`
- [ ] `show project area`
- [ ] `show topography`
- [ ] `show road route to Tanga port`
- [ ] `show route to power station`
- [ ] `show drillholes`
- [ ] `show resource model`
- [ ] `show high TGC area`
- [ ] `take me inside high TGC zone`
- [ ] `show metallurgy`
- [ ] `show peer comparison`
- [ ] `rotate 360`
- [ ] `show from below`
- [ ] `show from above`

## Acceptance Criteria

- [ ] First visible scene appears quickly.
- [ ] No blank black screen.
- [ ] Command bar remains usable.
- [ ] Voice status is understandable.
- [ ] Typed command fallback always works.
- [ ] Compass, scale, legend, and HUD do not overlap scene-critical content.
- [ ] Resource model appears below surface.
- [ ] Drillholes align with surface/resource model.
- [ ] Route readout shows distance/time or a clear fallback.
- [ ] Peer table values are readable and not clipped.
