# Tanga static 3D fallbacks

These stills are chapter-specific views captured from the local production build on 23 October 2026 at 1600 × 900 after the scene reported ready. Captures retain project geometry and rendering as a still image; presentation controls, callouts and legends were hidden during capture. The geology image uses the distinct interpreted-depth stage. The files are used only when the active Three.js scene reports an error.

These images preserve a view for presentation continuity; they are not an interactive model, source of geological interpretation, or replacement for the report evidence. Retry the scene to restore 3D interaction. If an image is unavailable, the existing scene error and retry message remain visible.
